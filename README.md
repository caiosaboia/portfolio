# Portfolio — Caio Saboia

Personal portfolio website presenting data engineering, machine learning, and AI projects, built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Features

- Static HTML export (`output: 'export'`) with zero server dependency
- Bilingual content (Portuguese and English) with browser-language client redirect
- Light and dark theme toggle respecting system preference
- Tested with Vitest and Testing Library
- Continuous deployment configured on `main` branch

## Development

```bash
npm install
npm run dev
```

## Testing

```bash
npm test
```

## Build

```bash
npm run build
```

Static files are output to the `out/` directory.
